# Mission Detailing

Responsive mobile detailing website mockup. Open index.html using a static web server. No build or dependencies required.

Includes a centered logo with scroll fade, Instagram work gallery, services, and appointment/quote links to @mission_detailing. Prices are intentionally omitted. Booking links open Instagram; appointments are confirmed directly with Javier.

## Assets

- assets/hero.svg: AI-generated illustrative concept photography.
- assets/logo-source.svg and assets/work-source.svg: pending permission to upload client imagery to this public repository. These two references will not load until the assets are added. The private preview includes them.

Edit index.html for copy and links, styles.css for appearance, and script.js for the logo fade. Replace the screenshot-derived gallery images with original client photographs when available.
